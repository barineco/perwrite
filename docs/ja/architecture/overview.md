# ドラフトを保持する文書編集

Perwrite は、同じ Markdown ファイルを表示するすべての画面で、一つのカスタム文書を共有します。入力・元に戻す・やり直す操作はドラフトを更新し、保存操作がドラフトをファイルへ書き込む構成です。

## 文書の状態

カスタム文書が保持する値は次のとおりです。

- 保存済み内容: 最後に確認したファイル内容
- ドラフト: 編集中の内容と選択範囲
- 外部変更: 編集中に観測したファイル内容
- 世代: 表示とのメッセージ順序を示す番号

dirty は、保存済み内容とドラフトのハッシュを比較して計算します。内容と dirty の関係は、この比較で一意に決まります。

## 編集

表示から送る値は次のとおりです。

- 文書識別子
- 世代
- 変更前の内容ハッシュ
- 文字列の変更
- 選択範囲

カスタム文書は各値を検証してからドラフトを更新します。受理した編集は VS Code のカスタム文書編集イベントとなり、編集前後のドラフトを保持します。

元に戻す操作とやり直す操作は、イベントが保持するドラフトを復元し、開いているすべての表示へ結果を通知します。エディタ表示は文字入力と選択範囲を提供し、カスタム文書は共有ドラフトと編集履歴を提供する役割分担です。

## 保存

保存手順は次のとおりです。

1. 物理ファイルを読み取る
2. 保存済み内容と比較する
3. 一致した場合にドラフトを書き込む
4. ファイルを再び読み取る
5. 観測内容がドラフトと一致した時に成功とする

保存成功時は保存済み内容を更新し、外部変更を解消します。保存失敗時はドラフト、選択範囲、編集履歴を保持します。

## 外部からのファイル変更

外部ファイルの観測結果は、文書の状態に応じて反映します。

- clean な文書: 観測内容を保存済み内容とドラフトへ採用
- 編集中の文書: ドラフトを保持して外部変更を記録

変更のない表示は即時更新され、編集中の文章は競合時にも保持されます。

## Backup と復元

Backup に保存する値は次のとおりです。

- 文書 URI
- 保存済み内容とハッシュ
- ドラフト内容
- 選択範囲
- 世代

復元時は保存形式とハッシュを検証します。物理ファイルが保存済み内容と一致する場合はドラフトを復元し、物理ファイルが変わっている場合は、その内容を外部変更として記録します。

## 複数表示

同じ Markdown ファイルの各表示は、一つのカスタム文書を参照します。どの表示から届いた編集も共有ドラフトを更新し、同じ世代ですべての表示へ通知されます。

パネルの破棄と再生成はカスタム文書の内容を保ちます。Git 比較の作業ツリー側も共有ドラフトを読むため、比較表示と通常編集は同じ未保存内容を表示します。

## ファイル操作

ファイル操作は一つの永続化モジュールが担当します。

- ファイルの読み取り
- 競合検査付きの書き込み
- 書き込み後の再観測
- Backup の保存

文書状態には、ファイルシステムの例外を渡さず、Perwrite の内容と失敗値を渡します。保存時の失敗は次の種類です。

- 外部変更との競合
- 権限不足
- ファイルの消失
- 書き込み失敗
- 書き込み後の内容不一致
- 再観測の失敗

## 保存する性質

この設計が保存する性質は次のとおりです。

- 入力・元に戻す・やり直す操作では物理ファイルが不変
- 保存成功時は現在のドラフトを反映
- 保存失敗時はドラフトと編集履歴を保持
- clean 時の外部変更はすべての表示へ反映
- 編集中の外部変更ではドラフトを保持
- パネル再生成後もドラフトと選択範囲を保持
- 再起動後は Backup から未保存内容を復元
- 複数表示でドラフトと編集履歴を共有
